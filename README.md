A make.fun entry for **[The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2)**
(`u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2`).

`main.py` writes one line — a robot vacuum explaining why it missed a spot:
it adopted the dust bunny living there, and you don't eat family — to
`/output/entry.txt` (83 characters, inside the 1–120 gate) and prints
exactly that line.

Run it:
